Descripció:
Branca main: El programa temperatrua comença amb una funcio definida a 25 graus, i la imprimeix per pantalla.
Branca Fahrenheit: Modififiquem el programa temperatura i ara converteix la temperatrua en graus fahrenheit. A més, ho imprimeix per pantalla.

Branca Classificacio: Modifiquem el programa de temperatura que hi ha al main que es el que imprimeix nomes la temperatura. Ara aqui el modifiquem per a que calsifiquiui si es una temperatura alta o baixa.

Compilacio:
Primer canviem a la branca que tingui la versio de la funcio que vulguem compilar.
Fem: gcc -Wall -Wextra temperatura.c -o temperataura
./temperatura
